**O que é HTML?**

HTML (HyperText Markup Language) é a linguagem utilizada para estruturar o conteúdo de uma página web. Com ele, podemos criar títulos, textos, imagens, links, botões, formulários e outros elementos que fazem parte da estrutura de um site.

**O que é CSS?**

CSS (Cascading Style Sheets) é a linguagem responsável pela aparência e estilização das páginas web. Com o CSS, podemos definir cores, fontes, tamanhos, espaçamentos, posicionamento dos elementos e também adaptar o site para diferentes tamanhos de tela.

**O que é JavaScript?**

JavaScript é uma linguagem de programação utilizada para adicionar interatividade e comportamentos às páginas web. Com ele, podemos criar ações como menus interativos, validação de formulários, animações, cálculos e comunicação com sistemas e APIs.
